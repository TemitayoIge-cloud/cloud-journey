# FILE SYSTEM HIERARCHY (FSH) IN LINUX.

#Everything in Linux is a FILE. Commands, devices, hard drives, printers etc are all files.
#In the root (/), there are a list of directories in there:
#1. /bin (bin directory-binaries): It stores a list of all the essential commands (command 
binaries)
#2. /sbin (super binaries): it stores special commands that only administrators would use.
#3. /usr (user directory): 
#4. /local (local directory): stores commands binaries that you might create.
#5. /lib (library directory): stores shared library files - what your system needs to boot/run
#6. /boot (boot directory): stores files needed by your system to boot.
#7. /var (var directory): stores log files and web app files.
#8. /tmp (temporary directory): stores temporary files that clears after a system reboot.
#9. /home (home directory): where every user lives.
#10./dev (devices directory): stores files for virtual disks and hard drives.
#11. /etc (etcetera directory): stores configuration files like network settings.
#12. /mnt: stores files to mount drives manually.
#13. /media: stores files to mount drives automatically.
