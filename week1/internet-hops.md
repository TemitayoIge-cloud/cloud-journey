# HOW DOES THE INTERNET WORK
#Data travels over the internet through PACKET SWITCHING. Instead of sending a message as one 
#continuous stream, the sender breaks it into small chunks called packets, and each packets travels independently to the destination.

# COMPONENTS OF A PACKET 
#1. HEADER: Source IP Address, Destination IP Address, Port numbers, Sequence.
#2. PAYLOAD: contains the actual data
#3. TRAILER: informs the destination that it has reached the end and checks for errors.
