# CAREER MAP
# TARGET ROLE: JUNIOR CLOUD ENGINEER 

#THE ROLE: I design, deploy, and maintain cloud infrastructure on AWS, keeping it secure,
#reliable, and cost efficient.

# PATH
#Months 0-6: Build foundations ,earn Cloud Practitioner certification, complete 3-6 solid 
#projects.

#Months 6-12: Land a first role: IT Support, Cloud Support Associate, or Junior Cloud 
#Engineer.

#Year 1-2: Cloud Engineer, owning infrastructure and automation.

# 5 Skills for the next 6 months

# 1. Linux and the Command Line (Months 1-2)
     #Navigation, permissions, processes, SSH, basic troubleshooting.
     
     #Proof: Set up and secure a Linux server you reach over SSH.

# 2. Networking Fundamentals (Months 1-2)
     #IP addressing, DNS, HTTP/HTTPS, subnets, firewalls.
     
     #Proof: Explain what happens when you open a website, step by step.

# 3. Core AWS services (Months 2-6)
     #IAM, EC2,S3, VPC, RDS,CloudWatch. Take Cloud Practitioner at Month 3, then start
     #Solutions Architect Associate.

     #Proof: Host a static site on S3 + CloudFront, then deploy an app on EC2 behind a load balancer.

# 4. Python/Bash scripting and Git (Months 2-4)
     #Automate small tasks, such as backing up files to S3. Use GitHub daily.

     #Proof: A public repo of working scripts with clear READMEs.

# 5. Infrastructure as Code and Docker (Months 4-6)
     # Terraform to define AWS resources, Docker to package apps, GitHub Actions for a simple pipeline.

     # Proof: Rebuild my EC2 project entirely in Terraform.


# MILESTONES
#Month 2: Comfortable in Linux: AWS account with billing alerts set.
#Month 3: Cloud Practitioner passed, first project live.
#Month 5: Terraform project on GitHub, start applying 
#Month 6: 3-6 projects, 1 certification, polished LinkedIn and CV.


# GROUND RULES
# 10-15 hours a week, at least 60% hands on labs
# Set a billing alert on day one and delete resources after each lab.
# Document every project with a diagram and README. Recruiters read these.
# Apply from Month 5, even if you don’t feel ready.
