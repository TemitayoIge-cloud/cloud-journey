# OPERATING SYSTEMS 

#WHAT IS AN OS?
#An Operating System (OS) is the software that sits between a computer’s hardware and every
#app that is run on it, managing the hardware’s resources and giving programs a way to use them
#them without each program needing to understand the hardware directly.

#OS is a program. It is usually the first to run when a computer starts.

# WHAT AN OS DOES?

#1. Process Scheduling 
#2. Memory Management 
#3. Hardware Abstraction 

#At the center of the OS, is the KERNEL: the core component that directly manages the CPU,
#memory and hardware. Everything else in the OS (the file manager, the GUI, background services)
#builds on the top of what the kernel provides.

# TYPES OF OPERATING SYSTEMS
#1. Desktop/Laptop OS (Windows, macOS, Linux desktop): general purpose computing.
#2. Server OS (Linux distros like Ubuntu Server, RHEL,Debian, Windows Server): built for 
#stability, security and running 24/7 without a GUI.
#3. Mobile OS (Android, iOS): optimized for touch, battery life and app sandboxing.
